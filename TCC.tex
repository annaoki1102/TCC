\begin{resumo2}
Profissionais de tecnologia precisam, com frequência, passar uma mesma regra de uma representação para outra, como de uma fórmula de planilha para um código. Quando a fórmula tem condições aninhadas, a lógica fica escondida e é fácil esquecer uma condição. Este trabalho propõe um protótipo que converte fórmulas de planilha com condições aninhadas em código Python e mostra a lógica em forma de fluxograma. A lógica da fórmula é organizada em uma árvore de condições, da qual saem o código e o fluxograma. A avaliação compara o resultado da fórmula com o do código em casos de teste e reúne a opinião de um profissional sobre a utilidade do fluxograma. O trabalho está em andamento: o problema, a proposta e o plano de avaliação estão definidos, e o desenvolvimento do protótipo será a próxima etapa.

\vspace*{20pt}
\textbf{Palavras-chave:} lógica computacional; fórmulas de planilha; conversão de código; fluxograma; Python.
\end{resumo2}

\begin{abstract}
Technology professionals often need to move the same rule from one representation to another, such as from a spreadsheet formula to code. When a formula has nested conditions, the logic is hidden and it is easy to miss a condition. This work proposes a prototype that converts spreadsheet formulas with nested conditions into Python code and shows the logic as a flowchart. The formula's logic is organized as a tree of conditions, from which the code and the flowchart are generated. The evaluation compares the formula's result with the code's result on test cases and collects a professional's opinion on the usefulness of the flowchart. The work is in progress: the problem, the proposal and the evaluation plan are defined, and the prototype development is the next step.

\vspace*{20pt}
\textbf{Keywords:} computational logic; spreadsheet formulas; code conversion; flowchart; Python.
\end{abstract}
