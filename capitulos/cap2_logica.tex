\section{Abstração e lógica computacional}

\subsection{Abstração}

A abstração é uma ideia central da computação. Com ela, um sistema complexo é descrito de forma simples, mostrando só o que importa para um determinado fim. Segundo \citeonline{abelson1996}, a abstração permite trabalhar um problema em diferentes níveis, sem precisar lidar com todos os detalhes de como ele é implementado.

No desenvolvimento de software, a abstração aparece em várias camadas, das linguagens de programação até as telas que o usuário vê. Cada camada esconde parte da complexidade da camada de baixo \cite{abelson1996}.

\subsection{Lógica independente da forma}

A lógica computacional é o conjunto de regras, decisões e passos que definem o que um sistema faz. Ela pode ser escrita de várias formas, e a forma não muda o que a lógica faz. \citeonline{knuth1968} mostra que um algoritmo existe independentemente da linguagem em que é escrito. A mesma solução pode ser escrita em linguagens diferentes, e o que muda é só a forma.

Uma decisão simples, como \textit{se a idade for maior ou igual a 18, é maior de idade, senão é menor}, pode ser escrita como um \texttt{if} em Python, como uma fórmula \texttt{SE} em uma planilha ou como um losango em um fluxograma. As três formas parecem diferentes, mas têm a mesma lógica.

Neste trabalho, \textbf{lógica} é o conjunto de regras e decisões, e \textbf{representação} é a forma usada para escrevê-las. Essa distinção é a base da proposta: se a lógica é separada da forma, é possível guardá-la de modo neutro e escrevê-la de novo em outra forma.

\subsection{Formas de representar a lógica}

As representações da lógica podem ser textuais ou visuais. As textuais incluem as linguagens de programação, o pseudocódigo e as fórmulas de planilha. As visuais usam desenhos, como os fluxogramas. Algumas existem só para descrever e comunicar um algoritmo, e outras podem ser executadas.

\citeonline{myers1990} organizou as formas de programação visual e de visualização de programas. A visualização de programas, que mostra visualmente um programa já existente, é diferente da programação visual, em que o programa é construído com elementos gráficos. Este trabalho usa o fluxograma como visualização: ele mostra a lógica de uma fórmula, mas não é onde o programa é construído.
